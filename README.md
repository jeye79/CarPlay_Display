# Ottocast Pro 야간 밝기 & 시계 (OttocastDimmer)

현대 넥소 차량용 **Ottocast Pro (안드로이드 AI Box)** 등 야간 운전 시 화면 눈부심을 줄이기 위한 초경량·초심플 안드로이드 앱입니다.

## 주요 기능

1. **원터치 즉시 실행 (자동 실행 없음)**
   - 앱 아이콘을 누르면 별도의 복잡한 창 없이 화면 맨 위 중앙에 **단 1개의 심플한 시계 캡슐**만 즉시 나타납니다.
   - 최초 실행 시에만 `다른 앱 위에 표시` 권한 허용을 안내합니다.
2. **상단 미니 시계 캡슐 조작**
   - **가볍게 터치(Tap)**: 슬림한 작은 작업창이 열립니다 (3.5초간 조작이 없거나 창 바깥을 터치하면 자동으로 다시 시계 캡슐로 접힙니다).
   - **좌우로 밀기(스와이프)**: 작업창을 열지 않고도 캡슐 위에서 좌우로 밀어 즉시 화면 밝기(`0% ~ 100%`)를 조절합니다.
   - **길게 누르기(0.5초 이상)**: 캡슐 테두리가 강조되며 상단 원하는 위치로 자유롭게 이동할 수 있습니다 (위치 자동 저장).
3. **작은 작업창 기능**
   - **시간 표시 (12시간 / 24시간 전환)**: 작업창 왼쪽 상단의 시계를 터치하면 `24시간제(15:36)` ↔ `12시간제(오후 3:36)`가 전환됩니다.
   - **밝기 조절바**: 좌우 슬라이더로 야간 화면 밝기를 세밀하게 조절합니다.
   - **블루라이트 차단바**: 눈이 편안한 따뜻한 색감의 블루라이트 차단 강도를 조절합니다.
   - **화면 끄기**: 내비 음성 안내나 음악은 그대로 유지한 채 화면 전체를 100% 완전 블랙(`#000000`)으로 덮고 시스템 밝기를 최소화합니다. 다시 켤 때는 **화면 아무 곳이나 한 번 터치**하면 즉시 복귀합니다.
   - **종료 (`✕`)**: 주간 주행 시 상단 캡슐과 필터를 완전히 종료합니다.

## APK 파일 위치 및 설치 방법

- 빌드된 설치 파일: `dist/OttocastDimmer.apk`
- USB 메모리 등에 `OttocastDimmer.apk`를 복사해 오토캐스트 프로의 파일 관리자에서 실행하여 설치하거나, PC와 ADB로 연결해 설치할 수 있습니다:
  ```bash
  adb install -r dist/OttocastDimmer.apk
  ```

## 직접 다시 빌드하기 (Windows PowerShell)

```powershell
powershell -ExecutionPolicy Bypass -File .\build_apk.ps1
```
